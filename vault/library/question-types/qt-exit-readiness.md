# At what price does this clear the return bar, and who are the natural buyers at exit?

## What resolves it
Comps analysis (`attested` public multiples + precedent transactions) beats sponsor reverse-engineered multiple.
Look for: EV/EBITDA multiple expansion built into base case ("we buy at 9x, sell at 11x") without a strategic rationale; buyer universe that narrows at exit if roll-up thesis fails; implied IRR that requires both multiple expansion AND margin improvement.
Cross-deal standard: a passing valuation requires the base-case IRR to hold with entry multiple = exit multiple; any return that requires >1.5x multiple expansion is speculative.
Leverage-driven returns: separate the IRR contribution of EBITDA growth, multiple, and debt paydown — if debt paydown >50% of total return, evaluate the downside leverage scenario explicitly.
Red flag: exit multiple assumption from a single 52-week high comp; buyer universe described as "strategic" without naming three realistic acquirers.
