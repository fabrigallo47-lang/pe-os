# PANTA Deal World V17 — Integration-Ready Handoff

V17 is the definitive frontend handoff for the first integrated PANTA product loop. It preserves the visual language and question-first interaction model of V16, restores the wider product experience developed in the Product Interaction Blueprint, and makes the boundary with Fabri's compiler and Anto's Transition Engine explicit.

## Open it

- macOS: double-click `START_PANTA.command`.
- Windows: run `START_PANTA_WINDOWS.bat`.
- Offline demo: open `OPEN_DEMO.html` or `app/index.html`.
- Full demo video: `demo/PANTA_V17_PRODUCT_DEMO.mp4`.

The local server uses only Python's standard library. Connected mode is available at `http://127.0.0.1:4177/?mode=connected`.

## What V17 contains

- Fund Command and Deal World in one universal shell.
- Question spine, Work, Foundations, Unknowns, Shadow IC, Artifacts and Registry.
- Object Aperture with Basis, Dependents, Action and History.
- Professional Review, Change Impact and Action Frontier.
- Scenario Lab, Decision Room and Execution Room.
- Causal Replay across Known, Believed, Approved and Open.
- A browser integration layer, projection adapters, mock API and sample payloads.
- Frozen backend schemas and V17 frontend contracts.
- Automated structural tests, screenshots and a product demo video.
- Frozen Blueprint, Engineering Source of Truth and Frontend Build Contract under `references/`.

## The integration rule

The frontend does not decide what is true, what changes, what is material or who must approve it. It projects outputs from the compiler, Live Investment Case, Transition Engine and policy layer.

- Fabri provides source-derived Current state, mappings, provenance and admitted events.
- Anto returns Candidate state, ordered consequences, financial recomputation, policy results, human stops, settlement and replay hash.
- V17 turns those outputs into one coherent product experience.

The raw backend files in `fixtures/backend_reference/` are preserved for integration work. They are not silently treated as correct product state. The embedded demo fixtures are synthetic and explicitly disclosed.
