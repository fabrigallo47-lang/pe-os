# Acceptance Tests

## Package gate

- `app/index.html` opens from `file://` without a server.
- `START_PANTA.command` opens connected mode.
- all JavaScript passes syntax checks;
- all JSON files parse;
- the browser self-test reports all tests green;
- screenshots render at 1440×900 and 1920×1080 without clipping;
- the demo video completes without console or page errors.

## Product-experience gate

- Fund Command and Deal World are visibly the same system at two scales;
- role switching changes emphasis but not facts;
- every major object opens through Object Aperture;
- Change Review shows source and proposed treatment separately;
- Change Impact uses backend dispositions and engine order;
- a human stop routes to Decision Room;
- execution is blocked until attestation;
- settlement returns to the same Deal World;
- Replay exposes Known, Believed, Approved and Open.

## Integration gate

- compiler payloads validate against frozen schemas;
- transition payloads validate against the frozen engine-output schema;
- frontend projection payloads validate against the V17 projection schemas;
- no browser code parses documents or recomputes financial formulas;
- no Candidate or authority result is produced by the compiler adapter;
- all unresolved objects are visible as coverage limits;
- Current and Approved do not change without the required professional or authority act.

## Domain gate

- Firm, QoE and Covenant EBITDA remain distinct;
- metric, definition, purpose, period, scenario, perimeter and unit are compatible before comparison;
- Case Positions are institutional propositions, not metric labels;
- support routes reflect real logical support and counterevidence;
- forecast period is not confused with known-at time;
- financial propagation agrees with the gold within declared tolerance;
- accepted-but-contested risk remains representable.
