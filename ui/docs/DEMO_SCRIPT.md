# V17 Demo Script

The included automated demo follows this sequence:

1. Fund Command opens on the Morning Delta.
2. Keystone is selected because a material financing exception made the offer basis stale.
3. The user zooms into Deal World and sees the underwriting-question spine.
4. Object Aperture reveals the customer-durability basis.
5. Foundations and Unknowns show what the case rests on and the highest-value open work.
6. A customer-master source arrives and is reviewed with its definition, period and perimeter.
7. The professional admits the treatment.
8. The Transition Engine returns ordered consequences, including recomputation, survival and a human stop.
9. Action Frontier prepares synchronized model, memo, offer and tracker changes.
10. Decision Room presents the authority request and three courses of action.
11. The partner attests the revised offer treatment.
12. Execution Room runs its pre-flight checks and simulates delivery.
13. The Deal World settles and Registry records the full path.
14. Causal Replay reconstructs the Final IC state.

Run it from the browser console with `PantaDemo.run()` or open `?autodemo=1`.
