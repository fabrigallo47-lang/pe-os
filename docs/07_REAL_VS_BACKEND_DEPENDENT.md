# What Is Real in Frontend vs Backend-Dependent

## Real frontend behavior
- one React application and routes
- shared shell / navigation
- case switching contract
- object selection + Object Lens composition
- sources drawer
- Find in case object results
- contextual Positions rendering
- structured evidence-quality display on Deal Home
- Trace support selection + temporary Test without this flow
- Simulate pre/post rendering + numeric coverage
- Review Admit/Correct/Reject controls
- Resolve work-item adoption/edit/dismiss/assignment controls
- Formation review/edit/adopt controls
- Replay calls case-as-of state
- actor/entitlement-aware decision controls
- Outputs read/edit/sync/diff surfaces

## Requires backend to become authoritative
- source ingestion/compiler
- ledger reduction into case-as-of snapshots
- graph relationship creation
- independent-evidence classification
- real causal/conditional propagation
- Findings generation
- quantity reconciliation/perimeter logic
- work-item execution status from real work
- reviewer/entitlement service
- artifact projection/synchronization engine
- durable version history

## Critical rule
The frontend must never fabricate these missing mechanics to make a screen look complete.
