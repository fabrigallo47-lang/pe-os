# Responsive Specification

| Width | Behavior |
|---|---|
| >=1440 | Full command center; three rails only when content does not clip. |
| 1024-1439 | Action rail overlays/collapses; context rail remains available. |
| 768-1023 | Contextual rails become drawers/sheets; dense data uses local horizontal scrollers. |
| <768 | Read/review-first mode; formal attestation and external execution blocked. |

No target viewport may produce page-level horizontal overflow.
