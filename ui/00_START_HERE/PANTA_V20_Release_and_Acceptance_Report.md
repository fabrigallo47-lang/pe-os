# Executive decision

PANTA V20 is accepted as the current product-experience, frontend, synthetic fixture and integration-handoff baseline. It extends V19.B to conversation-heavy, pre-revenue deep-tech venture diligence without changing the institutional state model or creating a venture-specific frontend.

# Delivered capability

- one universal kernel across Keystone, Orion and Tethys;
- hierarchical venture archetype, stage and sector overlay;
- four working governed Lenses;
- native Interactions, Participants and Utterances;
- observed-speech-act versus asserted-content separation;
- generated discrepancy candidates;
- deterministic derivations with formulas and hashes;
- AI hypotheses gated from propagation;
- governed question-spine changes;
- governed research, internal-analysis, outreach and physical-test missions;
- technical validation envelopes and condition edges;
- venture round, cap table, dilution, runway, milestones and reserves;
- populated Human Stop and blocked-component scenarios;
- expanded typed schemas and executable pure compiler/transition adapters;
- date-driven historical projection and event-derived replay;
- eleven new verified UI states.

# Acceptance result

The final executable suite passes **49/49** checks with zero failures.

# Important implementation corrections made during verification

1. The compiler adapter now normalises the temporal projection basis to `KNOWN_AT`, matching the public schema and server contract.
2. The epistemic regression explicitly allows an IC decision recorded in a transcript to remain `institutional_act` while requiring external utterance content to remain `asserted`.
3. The Scenario Lab now visibly labels the cap-table section, aligning the UI and browser acceptance contract.
4. All discrepancy generation is declarative; the generic core contains no case-specific IDs or facts.

# Generalisation evidence

- Tethys contains 30 claims, 6 interactions, 7 utterances and 9 venture questions.
- Exact normalised statement overlap with Keystone: 0.0%.
- Exact normalised statement overlap with Orion: 0.0%.
- No LBO-specific quantities appear in the venture case.
- The same renderer and server code serves all three cases.

# Integrity evidence

- Connected mode refuses fixture-backed data.
- All three live projections and contexts validate with zero schema errors.
- Compiler and transition adapters are pure and deterministic.
- Human Stop settlement is refused without scoped authority.
- Authority rejects mismatched Candidates and cannot be reused across runs.
- Conflicting courses cannot coexist.
- Changes outside the transition output are refused.
- Blocked scope requires explicit bounded partial settlement.
- Failed execution never reports success.
- Replay does not write to Registry.

# Release boundary

V20 is not a claim of production deployment. The package does not contain production SSO/RBAC, tenant-aware durable Case Store persistence, live autonomous research, human outreach, physical testing, real external delivery, Fabri's production compiler or Anto's separate production runtime. The mock runtime is explicitly synthetic and no-external-effects.

# Supersession

V20 supersedes V19.B for active implementation, venture capability, schemas, adapters, API and demonstration. V19/V19.B professional material remains historical reference for unchanged architecture. Frozen machine contracts and conformance tests continue to outrank this release prose.
