# Is the revenue base programmatic/contracted or repeat-project/discretionary?

## What resolves it
`attested` MSA/contract backlog beats seller-asserted renewal rates. Distinguish:
- Programmatic: fee-for-service embedded in client workflows (high durability)
- Project-based: rebid per engagement (durability depends on win rate and relationship depth)
- Recurring: same customer, same scope annually — but could be terminated with notice
Cross-deal standard: <60% programmatic = underwrite more conservatively; check client interviews.
