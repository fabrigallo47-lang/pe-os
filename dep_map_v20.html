Critical Gaps — 4 structural mismatches blocking V20 frontend
GAP 1 No server on :4191. store.js defaults apiBase to http://127.0.0.1:4191/api/v20. server.py is on :8787, ui_bridge.py is on :4178. Every V20 call fails with ECONNREFUSED before leaving the browser. PAN-11 fixes server.py port.
GAP 2 No /api/v20 routes anywhere. server.py has /api/* (34 routes). ui_bridge.py has /api/v1/* (V1 only). The 9 V20 endpoints api.js calls (bootstrap, projection, sources, inbox, ingest, jobs, admit, search) do not exist. PAN-12 through PAN-18.
GAP 3 ui_bridge.py + ui_projection.py are V1. ui_projection.py builds schema_version "frontend-projection/1.0". contracts.js validateProjection() expects "frontend-projection/20.0". Even if port is fixed, ui_bridge's response will fail the frontend validation gate and throw UNSUPPORTED_PROJECTION.
GAP 4 projection_adapter.js (PantaProjectionAdapter) + v20_extension.js (32KB, patches PantaActions) exist in frontend but have no backend counterpart. These were not in the original dep map — discovered by code scan. v20_extension.js extends the engine with V20-specific behaviour that has never been exercised against a live backend.
