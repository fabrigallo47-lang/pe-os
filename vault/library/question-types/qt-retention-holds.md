# Does retention hold at the underwritten level?

## What resolves it
Cohort tables from raw data (`derived` resting on `observed`) beat blended churn statements (`asserted`). Customer reference calls yield `observed` evidence that no one else has — e.g. "we'd churn if the founder left" — which is exactly the class of proprietary interaction data this library exists to keep findable.
