# Accessibility Specification

- One main landmark.
- Dialog and Object Aperture use labelled dialog/tab patterns, focus trap and focus restoration.
- Page changes focus the page title; local control changes retain equivalent focus.
- Root application is not a live region; a small atomic status region announces critical progress.
- State is represented by text, icon and color.
- Normal text meets 4.5:1; non-text/state boundaries meet 3:1.
- Formal authority is desktop-only below 768px.
