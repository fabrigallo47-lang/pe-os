# PANTA Visual System V4 FINAL

## Consistency lives in the system

Shared across rooms:
- Global Shell and breadcrumb geometry
- graphite/mineral material palette
- warm off-white human language
- sans prose + mono only for true machine metadata
- spacing scale and hairline grammar
- action/button grammar
- Object Lens
- truthful relation/provenance marks
- restrained state transition motion

## Identity lives in the task

Consistency does not mean sameness:

- Deal Home — situational scan / command
- Workstream — internal reasoning structure
- Trace — evidence inspection
- Simulate — sensitivity / propagation
- Review — human judgment
- Resolve — evidence-route design
- Formation — case assembly
- Replay — time / state rewind
- Decision — commitment
- Outputs Memo — live document / authoring
- Outputs Model — spreadsheet / financial instrument
- Decision Pack — decision artifact

## Investor-language rule

The engine may use Question, CaseReading, relations, coverage, typed quantities and ledger events. The UI translates those mechanics into ordinary investor questions:

- Why we believe this
- Still missing
- Why it matters
- What changed
- What changes if this moves
- Where else this appears

## Visual prohibitions

- no traffic-light dots as primary semantics
- no generic card grid everywhere
- no soft shadows / sci-fi glow
- no permanent AI-assistant panel
- no explanatory machine filler
- no decorative connector line — a line must encode a real relationship
- no visual state that implies certainty/authority the backend has not established
