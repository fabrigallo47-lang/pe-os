# PANTA V19 Content Design Guide

- Name the object before the action.
- Distinguish evidence, belief, model assumption, computed result and approved decision.
- Use Current, Working and Approved only for institutional state.
- Never use Sent, Routed, Approved or Settled without a server acknowledgement.
- Explain every disabled action with the missing prerequisite.
- Keep locators precise but secondary to semantic meaning.
- Preserve source wording in exact passages; paraphrase only in explicitly labelled interpretation.
